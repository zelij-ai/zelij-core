*ഒരു സിമുലേറ്റഡ് ദിവസത്തിലെ അക്വേറിയം (ഇവിടെ ഫ്രഞ്ചിൽ). നിങ്ങളുടെ ഇൻസ്റ്റാളേഷനിൽ ഓരോ കാർഡും നിങ്ങളുടെ ഏജന്റുമാരുടെ യഥാർത്ഥ പ്രവൃത്തിയാണ്, തത്സമയവും ഇരുപത്തിനാല് മണിക്കൂർ റീപ്ലേ ചെയ്യാവുന്നതും. സ്വർണ്ണനിറം നിങ്ങളാണ്: നിങ്ങളുടെ തീരുമാനത്തിന് മുമ്പ് ബാധ്യതയുള്ള ഒന്നും സംഭവിക്കില്ല. മുഖങ്ങൾ സാങ്കൽപ്പിക കഥാപാത്രങ്ങളുടേതാണ്.*

## കോർ എന്തു ചെയ്യുന്നു

- **ഓഫീസ്**: ഒരു പേജ്. കാത്തിരിക്കുന്ന തീരുമാനങ്ങൾ, ചീഫ് ഓഫ് സ്റ്റാഫിനോടുള്ള ഒരു അഭ്യർത്ഥന, ചെലവ് സഹിതം ഏറ്റവും പുതിയ റണ്ണുകൾ, ജേണൽ, ഏജന്റുമാർ, ഇൻസ്റ്റാൾ ചെയ്ത മൊഡ്യൂളുകൾ.
- **തീരുമാന പാക്കറ്റ്**: ലക്ഷ്യം, നിർദ്ദേശം, എന്തുകൊണ്ട് ഇപ്പോൾ, ഓപ്ഷനുകൾ, ശുപാർശ, അപകടസാധ്യതകൾ, തിരിച്ചുപോകാനാകുമോ, പദ്ധതി, റോൾബാക്ക്, സ്വാധീനം. അപൂർണ്ണമായ പാക്കറ്റ് തുറക്കില്ല. അംഗീകരിക്കുക, നിരസിക്കുക, അല്ലെങ്കിൽ ഏജന്റിന് കൈമാറുന്ന നിർബന്ധിത നിർദ്ദേശത്തോടെ മാറ്റങ്ങൾ ആവശ്യപ്പെടുക.
- **വീട്ടുനിയമങ്ങൾ**: ബാധ്യതയുള്ള ഒന്നും (പണം, പൊതു വെളിപ്പെടുത്തൽ, ഇല്ലാതാക്കൽ, തിരിച്ചെടുക്കാനാകാത്തത്) തീരുമാനമില്ലാതെ ചെയ്യില്ല; ഓരോ വസ്തുതയ്ക്കും തീയതിയും ഉറവിടവും ഉണ്ടാകും, അല്ലെങ്കിൽ «പരിശോധിച്ചിട്ടില്ല» എന്ന് അടയാളപ്പെടുത്തും; ജേണൽ ഒരിക്കലും മായ്ക്കില്ല.
- **ഗേറ്റ്‌വേ**: സ്ഥാപകന്റെ Claude കീ, ഉപയോഗത്തിൽ നിന്നും തീയതിയുള്ള പൊതു നിരക്കുകളിൽ നിന്നും കണക്കാക്കുന്ന ഓരോ കോളിന്റെയും ചെലവ്, എത്തിയാൽ തടയുന്ന പ്രതിമാസ പരിധി.
- **എക്സിക്യൂട്ടർ**: പരിധിയുള്ള കോൾ ലൂപ്പ് (ഏജന്റിന് ഒരു ടേൺ ബജറ്റ്), മിതമായ ടൂളുകൾ, മോഡലിന്റെ നിരസനം ഒരു ഫലമായി പരിഗണിക്കുന്നു.
- **മൊഡ്യൂളുകൾ**: കോർ വിപുലീകരിക്കാനുള്ള ഏക വഴി. സ്ഥിരമായ ഇന്റർഫേസ്, പ്രസാധകൻ Ed25519 ഉപയോഗിച്ച് ഒപ്പിട്ട `pack.json` മാനിഫെസ്റ്റ്, ഓരോ ഫയലിന്റെയും ഹാഷ് ഒപ്പിന്റെ പരിധിയിൽ, ഇൻസ്റ്റാളേഷന് മുമ്പ് പരിശോധന. ഡിപ്ലോയ്മെന്റ് ലക്ഷ്യങ്ങളും അധിക ഏജന്റുമാരും ഇതുവഴി മാത്രം വരുന്നു.
- **ധനകാര്യം**: സ്ഥിരീകരിച്ച വിൽപ്പനകൾ (റീഡ്-ഒൺലി Stripe ഇംപോർട്ട് അല്ലെങ്കിൽ തെളിവോടെയുള്ള മാനുവൽ എൻട്രി), എല്ലാ മാസവും ആവർത്തിക്കുന്ന പ്രഖ്യാപിത ചെലവുകൾ, അളന്ന ഏജന്റ് ചെലവ്, മാസ ജേണൽ, അക്കൗണ്ടന്റിനുള്ള CSV എക്സ്പോർട്ട്. ഒന്നും ഫയൽ ചെയ്യുകയോ ഇൻവോയ്സ് ചെയ്യുകയോ ഇല്ല.
- **കോൺടാക്റ്റുകൾ**: ഒരാൾക്ക് ഒരു കാർഡ്, നിർബന്ധിത നിയമപരമായ അടിസ്ഥാനം, സൂക്ഷിപ്പ് കാലാവധി, ആശയവിനിമയങ്ങൾ, വിനിയോഗിച്ച അവകാശങ്ങൾ; എതിർപ്പ് പ്രകടിപ്പിച്ച കോൺടാക്റ്റിന് പിന്നീടൊന്നും ലഭിക്കില്ല, കാലാവധി കഴിഞ്ഞ കോൺടാക്റ്റ് മറക്കപ്പെടും, അവകാശ ജേണൽ മാത്രം ശേഷിക്കും.
- **പ്രസിദ്ധീകരണം**: മാർക്കറ്റിംഗ് ഏജന്റ് എഴുതിയ പേജ് ആദ്യം ഡ്രാഫ്റ്റും പിന്നെ തീരുമാനവുമാകുന്നു; അംഗീകരിച്ചാൽ GitHub പുൾ റിക്വസ്റ്റായോ WordPress ഡ്രാഫ്റ്റായോ സൈറ്റിലേക്ക് നിർദ്ദേശിക്കപ്പെടുന്നു. അവസാന നീക്കം, മെർജ് ചെയ്യുകയോ പ്രസിദ്ധീകരിക്കുകയോ, നിങ്ങളുടേതാണ്.
- **പോക്കറ്റിൽ**: ഓരോ തീരുമാനവും നിങ്ങളുടെ ഫോണിലെത്തുന്നു, രണ്ട് ഒപ്പിട്ട ഒറ്റത്തവണ ലിങ്കുകളുള്ള ഇ-മെയിൽ വഴിയോ മൂന്ന് ബട്ടണുകളുള്ള Telegram വഴിയോ. മെട്രോ ക്യൂവിൽ നിന്ന് നിങ്ങൾ അംഗീകരിക്കുന്നു; മറുപടി നൽകിയ ഉടൻ അക്വേറിയം ചലിക്കുന്നു. മേശയിൽ നിന്നുള്ള അതേ വാതിൽ, അതേ ജേണൽ.
- **അക്വേറിയം**: നിങ്ങളുടെ ഏജന്റുമാർ പ്രവർത്തിക്കുന്നത് കാണുക; ഓരോ കുമിളയും കഴിഞ്ഞ 24 മണിക്കൂറിലെ യഥാർത്ഥ പ്രവൃത്തിയാണ്, കുത്തിട്ട വളയങ്ങൾ ഒഴിഞ്ഞ തസ്തികകൾ. «by zelij.ai» ബാഡ്ജോടെ പങ്കിടാവുന്ന പൊതു പേജ്.
- **കാറ്റലോഗ്**: സൗജന്യ പതിപ്പിൽ ഇല്ലാത്തത്, സത്യസന്ധമായി പേരിട്ടത്; പ്രസാധകനിൽ നിന്ന് വാങ്ങിയ മൊഡ്യൂൾ ഇവിടെ ഒപ്പിട്ട് പരിശോധിച്ച് ഇൻസ്റ്റാൾ ചെയ്യുന്നു. ഒരു പണമിടപാടും ഓഫീസിലൂടെ കടന്നുപോകുന്നില്ല.
- **സോഫ്റ്റ്‌വെയർ ഫാക്ടറി**: ബിൽഡർ ഒരൊറ്റ റിപ്പോസിറ്ററിയിൽ മാത്രം വായിക്കുകയും നിർദ്ദേശിക്കുകയും ചെയ്യുന്നു, സുരക്ഷാ ഗേറ്റ് കടക്കുന്ന പുൾ റിക്വസ്റ്റുകളിലൂടെ (300 വരികൾ, ടെക്സ്റ്റ് മാത്രം, രഹസ്യങ്ങളില്ല, ഇൻഫ്രാസ്ട്രക്ചർ ഫയലുകളില്ല, OSV പ്രകാരം അറിയപ്പെടുന്ന ദുർബലതകളില്ലാത്ത ഡിപ്പൻഡൻസികൾ); SSH വഴി Linux സെർവറിലേക്കോ OVH-ലേക്കോ (API വഴി ഡൊമെയ്നും DNS-ഉം) ആറ്റോമിക് സ്വിച്ച്, സ്മോക്ക് ടെസ്റ്റ്, റോൾബാക്ക് എന്നിവയോടെ ഡിപ്ലോയ്മെന്റ്; ഡൊമെയ്ൻ പ്രോബ്; ഓഫീസിന്റെ ദൈനംദിന ബാക്കപ്പ്. അത് ഒരിക്കലും മെർജ് ചെയ്യില്ല, ഒരിക്കലും പണമടയ്ക്കില്ല, ഒരിക്കലും ഓഫീസിനെ തൊടില്ല.
- **ഏജന്റുമാർ**: ഓരോ ഏജന്റിനും ഒരു ഫോൾഡർ, ലളിതമായ ഹെഡറും ഫ്രഞ്ചിലുള്ള നിർദ്ദേശങ്ങളുമുള്ള ഒരു `agent.md`. നാല് ഏജന്റുമാർ: Camille Aubert (ചീഫ് ഓഫ് സ്റ്റാഫ്), Élise Tanguy (വളർച്ച, മാർക്കറ്റിംഗ്, ഉൽപ്പന്നങ്ങൾ), Nour Bellamy (ധനകാര്യവും ഉപഭോക്താക്കളും), Sacha Ferrand (ബിൽഡർ, സോഫ്റ്റ്‌വെയർ ഫാക്ടറി). സ്ഥാപകൻ ഓഫീസിൽ നിന്ന് ഓരോരുത്തരോടും സംസാരിക്കുന്നു; ഏജന്റിനെയും ടാസ്കിനെയും പേരെടുത്തു പറയുന്ന അംഗീകൃത പാക്കറ്റ് പദ്ധതിയുടെ പരിധിക്കുള്ളിൽ ഉടൻ നടപ്പാകുന്നു.

## കീ ഇല്ലാതെ ഒരു മിനിറ്റിൽ പരീക്ഷിക്കുക

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

`http://localhost:8000` തുറന്ന് ഡെമോയിൽ പ്രവേശിക്കുക: ഒരു സാങ്കൽപ്പിക കമ്പനി, നാല് സിമുലേറ്റഡ് ഏജന്റുമാർ, അംഗീകരിക്കാനുള്ള തീരുമാനങ്ങൾ, അവരുടെ ദിവസം റീപ്ലേ ചെയ്യുന്ന അക്വേറിയം. കീ ഇല്ല, അക്കൗണ്ട് ഇല്ല, ചെലവില്ല; ഒരു മോഡലിലേക്കും ഒന്നും അയയ്ക്കുന്നില്ല, നിർത്തുമ്പോൾ എല്ലാം അപ്രത്യക്ഷമാകുന്നു. ബോധ്യമായാൽ താഴെയുള്ള യഥാർത്ഥ ഇൻസ്റ്റാളേഷനിലേക്ക് പോകുക. ഓഫീസ് തന്നെ ഫ്രഞ്ചിലാണ്.

## ആരംഭിക്കുക

```bash
cp .env.example .env     # Claude കീ, പരിധി, SECRET_KEY, ഡാറ്റാബേസ് പാസ്‌വേഡ്
docker compose up -d --build
```

ഓഫീസ് `http://localhost:8000`-ൽ പ്രതികരിക്കുന്നു. SMTP ഇല്ലെങ്കിൽ ലോഗിൻ ലിങ്ക് കണ്ടെയ്നർ ലോഗുകളിൽ എഴുതപ്പെടും (`docker compose logs core-app`).

പൂർണ്ണ ഗൈഡുകൾ (ഇംഗ്ലീഷിൽ): **[ഇൻസ്റ്റാളേഷൻ](docs/INSTALLATION.en.md)** (ശൂന്യമായ മെഷീൻ മുതൽ https-ലെ ഓഫീസ് വരെ, SMTP, സോഫ്റ്റ്‌വെയർ ഫാക്ടറി, ബാക്കപ്പുകൾ, പ്രശ്നപരിഹാരം), **[ഉപയോക്തൃ ഗൈഡ്](docs/MODE-D-EMPLOI.en.md)** (ഓരോ പേജും, ഏജന്റുമാർ, തീരുമാനങ്ങൾ, ചെലവ്). സ്ഥാപകന്റെയും ഏജന്റുമാരുടെയും ഫോട്ടോകൾ [`portraits/`](portraits/README.md)-ൽ വയ്ക്കുക (വിവരണം ഫ്രഞ്ചിൽ).

പ്രസിദ്ധീകരിച്ച ഇമേജിൽ നിന്ന്, ലോക്കൽ ബിൽഡ് ഇല്ലാതെ (പതിപ്പ് ഉറപ്പിക്കാൻ `.env`-ൽ `CORE_IMAGE_TAG=v…`):

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

Docker ഇല്ലാതെ ലോക്കലായി:

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## സുരക്ഷ

കോർ ഉറപ്പുനൽകുന്നതും പരീക്ഷിക്കപ്പെടുന്നതും (`tests/test_securite.py`):

- **മൊഡ്യൂളുകൾ**: പ്രസാധകൻ ഒപ്പിട്ടാൽ (Ed25519) മാത്രമേ മൊഡ്യൂൾ ഇൻസ്റ്റാൾ ചെയ്യുകയും പ്രവർത്തിക്കുകയും ചെയ്യൂ, ഒപ്പ് ഓരോ കോഡ് ഫയലിന്റെയും SHA-256 ഹാഷ് ഉൾക്കൊള്ളുന്നു: ഒപ്പിനു ശേഷം മാറ്റിയതോ ചേർത്തതോ നീക്കിയതോ ആയ ഫയൽ മൊഡ്യൂളിനെ അസാധുവാക്കുന്നു.
- **ലോഗിൻ**: 20 മിനിറ്റ് സാധുതയുള്ള ഒറ്റത്തവണ ലിങ്കുകൾ, ഡാറ്റാബേസിൽ ഹാഷ് ചെയ്തത്; ലിങ്ക് അഭ്യർത്ഥനകളിൽ വിലാസം, IP, മൊത്തം എന്നിങ്ങനെ ബ്രേക്കുകൾ, അങ്ങനെ ഓഫീസ് ഒരിക്കലും ഇ-മെയിൽ റിലേ ആകില്ല; പ്രൊഡക്ഷനിൽ SMTP ക്രമീകരിച്ചിട്ടില്ലെങ്കിൽ ലിങ്ക് സൃഷ്ടിക്കുകയോ ലോഗ് ചെയ്യുകയോ ഇല്ല.
- **ഫോമുകൾ**: HMAC സെഷൻ കുക്കി `HttpOnly` `SameSite=Strict`, ഓരോ POST-ലും ഒറിജിൻ പരിശോധനയും സെഷനുള്ള ആന്റി-CSRF ടോക്കണും.
- **പേജുകൾ**: കർശനമായ കണ്ടന്റ് സെക്യൂരിറ്റി പോളിസി (`default-src 'self'`, ഇൻലൈൻ സ്ക്രിപ്റ്റില്ല, ഫ്രെയിമില്ല), `nosniff`, `X-Frame-Options`, `Referrer-Policy`, ഒറിജിൻ https ആണെങ്കിൽ HSTS.
- **ഏജന്റുമാർ**: ഏജന്റ് വായിക്കുന്നതെന്തും (വെബ് പേജ്, റിപ്പോസിറ്ററി ഫയൽ) ബാഹ്യ ഉള്ളടക്കമായി ഫ്രെയിം ചെയ്താണ് എത്തുന്നത്, ഒരിക്കലും നിർദ്ദേശമായല്ല; ഏജന്റ് തന്റെ കാർഡിലെ ടൂളുകൾ മാത്രം പ്രവർത്തിപ്പിക്കുന്നു, സ്വകാര്യ ഡാറ്റ വായിച്ചുകഴിഞ്ഞാൽ കമ്പനിയുടെ സ്വന്തം സൈറ്റ് മാത്രമേ വിളിക്കാനാകൂ; പൊതു https വിലാസങ്ങൾ മാത്രം വായിക്കുന്നു (സ്വകാര്യ, ലൂപ്പ്ബാക്ക്, ലിങ്ക്-ലോക്കൽ വിലാസങ്ങളും ആന്തരിക പേരുകളും ഓരോ റീഡയറക്ട് ഹോപ്പിലും നിരസിക്കപ്പെടുന്നു, പ്രതികരണത്തിന് പരിധിയുണ്ട്); സുരക്ഷാ ഗേറ്റ് രഹസ്യങ്ങൾ, ഇൻഫ്രാസ്ട്രക്ചർ ഫയലുകൾ, മൂന്നാം കക്ഷി സ്ക്രിപ്റ്റുകൾ, ഫ്രെയിമുകൾ, നെറ്റ്‌വർക്ക് കോളുകൾ എന്നിവ തടയുന്നു.
- **കണ്ടെയ്നർ**: പ്രത്യേകാവകാശമില്ലാത്ത ഉപയോക്താവ്, റീഡ്-ഒൺലി ഫയൽ സിസ്റ്റം, കേപ്പബിലിറ്റികളില്ല, പ്രിവിലേജ് ഉയർത്തലില്ല; SSH സെർവറിന്റെ ഹോസ്റ്റ് കീ ഉറപ്പിക്കാം (`SSH_CLE_HOTE`).
- **അക്കൗണ്ടിംഗ് എക്സ്പോർട്ട്**: സ്പ്രെഡ്ഷീറ്റ് ഫോർമുല പോലെ തോന്നുന്ന സെല്ലുകൾ നിർവീര്യമാക്കുന്നു.

ദുർബലത റിപ്പോർട്ട് ചെയ്യാൻ: `securite@zelij.ai`, പരിഹാരത്തിന് മുമ്പ് പരസ്യപ്പെടുത്താതെ. ഓരോ റിലീസിനും മുമ്പ് `pip-audit -r requirements.txt`, `bandit -r core scripts -ll` എന്നിവ ശൂന്യമായിരിക്കണം.
