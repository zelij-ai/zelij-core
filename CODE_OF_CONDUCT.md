# Règles de bonne conduite

Ce dépôt est un lieu de travail. On y vient pour améliorer un outil que des fondateurs utilisent tous les jours.

- **On parle du code et des faits**, pas des personnes. Une critique dit ce qui ne va pas et pourquoi ; elle ne juge pas celui qui l'a écrit.
- **On répond aux questions avec la même précision qu'on attend des agents** : daté, sourcé, vérifiable.
- **On n'expose personne** : pas de données réelles dans les issues (adresses, noms de clients, clés), pas de capture d'écran avec des informations privées.
- **On accueille les débutants** : une première contribution maladroite reçoit des indications, pas une leçon.
- **Les décisions sur le périmètre reviennent à l'éditeur**, qui les explique. Un désaccord se discute dans l'issue, une fois, calmement.

Harcèlement, insultes, discrimination, publication d'informations privées : exclusion immédiate du dépôt, sans débat. Pour signaler un comportement : securite@zelij.ai.
