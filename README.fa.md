**استارتاپ ۱۰۰٪ بومیِ هوش مصنوعی خود را بسازید.** یک دفتر که در آن چهار عامل برای شما کار می‌کنند: آن‌ها پیشنهاد می‌دهند، شما تصمیم می‌گیرید. دستگاه شما، کلید Claude شما، داده‌های شما؛ هیچ‌چیز به جایی گزارش نمی‌فرستد.

![آکواریوم Zelij Core: بنیان‌گذار و چهار عامل گفت‌وگو می‌کنند، تصمیم پیشنهاد می‌دهند و آنچه تأیید شده را اجرا می‌کنند](docs/img/aquarium.gif)

*آکواریوم در یک روز شبیه‌سازی‌شده (اینجا به فرانسوی). در نصب شما، هر کارت یک اقدام واقعی عامل‌های شماست، زنده و قابل بازپخش در بیست‌وچهار ساعت. طلایی شما هستید: هیچ کار الزام‌آوری پیش از تصمیم شما انجام نمی‌شود. چهره‌ها متعلق به شخصیت‌های خیالی‌اند.*

## هسته چه می‌کند

- **دفتر**: یک صفحه. تصمیم‌های در انتظار، درخواستی به رئیس دفتر، آخرین اجراها با هزینه‌شان، دفتر وقایع، عامل‌ها، ماژول‌های نصب‌شده.
- **بستهٔ تصمیم**: هدف، پیشنهاد، چرا اکنون، گزینه‌ها، توصیه، ریسک‌ها، برگشت‌پذیری، برنامه، بازگشت، اثر. بستهٔ ناقص باز نمی‌شود. تأیید، رد، یا درخواست تغییر با دستورالعملی الزامی که به عامل منتقل می‌شود.
- **قواعد خانه**: هیچ کار الزام‌آوری (پول، نمایش عمومی، حذف، برگشت‌ناپذیر) بدون تصمیم انجام نمی‌شود؛ هر واقعیت تاریخ و منبع دارد یا «تأییدنشده» علامت می‌خورد؛ دفتر وقایع هرگز پاک نمی‌شود.
- **دروازه**: کلید Claude بنیان‌گذار، هزینهٔ هر فراخوانی که از مصرف و قیمت‌های عمومی تاریخ‌دار محاسبه می‌شود، سقف ماهانه‌ای که مسدود می‌کند.
- **اجراکننده**: حلقهٔ فراخوانی محدود (بودجهٔ نوبت برای هر عامل)، ابزارهای کم‌خرج، امتناع مدل به‌عنوان یک نتیجه در نظر گرفته می‌شود.
- **ماژول‌ها**: تنها راه گسترش هسته. رابط پایدار، مانیفست `pack.json` امضاشده با Ed25519 توسط ناشر، هش هر فایل زیر پوشش امضا، بررسی پیش از نصب. مقصدهای استقرار و عامل‌های اضافی همگی از این مسیر می‌آیند.
- **مالی**: فروش‌های تأییدشده (ورود فقط‌خواندنی از Stripe یا ثبت دستی با مدرک)، هزینه‌های اعلام‌شده که هر ماه تکرار می‌شوند، هزینهٔ اندازه‌گیری‌شدهٔ عامل‌ها، دفتر ماه، خروجی CSV برای حسابدار. هیچ‌چیز اظهار یا صورت‌حساب نمی‌شود.
- **مخاطبان**: یک کارت برای هر نفر، مبنای قانونی الزامی، مدت نگهداری، مکاتبات، حقوق اعمال‌شده؛ مخاطب معترض دیگر چیزی دریافت نمی‌کند، مخاطب منقضی فراموش می‌شود و تنها دفتر حقوق باقی می‌ماند.
- **انتشار**: صفحه‌ای که عامل بازاریابی می‌نویسد ابتدا پیش‌نویس و سپس یک تصمیم می‌شود؛ پس از تأیید، به‌عنوان pull request در GitHub یا پیش‌نویس WordPress به سایت پیشنهاد می‌شود. گام آخر، ادغام یا انتشار، با شماست.
- **در جیب شما**: هر تصمیم به تلفن شما می‌رسد؛ با ایمیل حاوی دو پیوند امضاشدهٔ یک‌بارمصرف، یا با Telegram با سه دکمه. در صف مترو تأیید می‌کنید؛ آکواریوم به‌محض پاسخ شما حرکت می‌کند. همان دروازه، همان دفتر وقایعِ پشت میز.
- **آکواریوم**: عامل‌های خود را در حال کار تماشا کنید؛ هر حباب یک اقدام واقعی از ۲۴ ساعت گذشته است، حلقه‌های نقطه‌چین پست‌های خالی‌اند. یک صفحهٔ عمومی قابل اشتراک، با نشان «by zelij.ai».
- **کاتالوگ**: آنچه نسخهٔ آزاد ندارد، صادقانه نام‌گذاری شده؛ ماژولی که از ناشر خریده‌اید اینجا، امضاشده و بررسی‌شده، نصب می‌شود. هیچ پرداختی از دفتر عبور نمی‌کند.
- **کارخانهٔ نرم‌افزار**: سازنده فقط روی یک مخزن می‌خواند و پیشنهاد می‌دهد، از طریق pull requestهایی که از دروازهٔ امنیتی می‌گذرند (۳۰۰ خط، فقط متن، بدون راز، بدون فایل زیرساخت، وابستگی‌های بدون آسیب‌پذیری شناخته‌شده طبق OSV)؛ استقرار روی سرور Linux با SSH یا در OVH (دامنه و DNS از طریق API) با تعویض اتمی، تست دود و بازگشت؛ پایش دامنه؛ پشتیبان‌گیری روزانهٔ دفتر. هرگز ادغام نمی‌کند، هرگز پرداخت نمی‌کند، هرگز به دفتر دست نمی‌زند.
- **عامل‌ها**: یک پوشه برای هر عامل، یک `agent.md` با سرآیند ساده و دستورالعمل‌هایی به فرانسوی. چهار عامل: Camille Aubert (رئیس دفتر)، Élise Tanguy (رشد، بازاریابی و محصولات)، Nour Bellamy (مالی و مشتریان)، Sacha Ferrand (سازنده، کارخانهٔ نرم‌افزار). بنیان‌گذار از دفتر با هر یک مستقیماً صحبت می‌کند؛ بستهٔ تأییدشده‌ای که عامل و وظیفه را مشخص کند بلافاصله، در محدودهٔ برنامه، اجرا می‌شود.

## در یک دقیقه امتحان کنید، بدون کلید

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

`http://localhost:8000` را باز کنید و وارد نمایش شوید: یک شرکت خیالی، چهار عامل شبیه‌سازی‌شده، تصمیم‌هایی برای تأیید، آکواریومی که روزشان را بازپخش می‌کند. بدون کلید، بدون حساب، بدون هزینه؛ هیچ‌چیز به مدلی فرستاده نمی‌شود و با توقف همه‌چیز ناپدید می‌شود. وقتی قانع شدید، به نصب واقعی در ادامه بروید. خودِ دفتر به زبان فرانسوی است.

## راه‌اندازی

```bash
cp .env.example .env     # کلید Claude، سقف، SECRET_KEY، گذرواژهٔ پایگاه داده
docker compose up -d --build
```

دفتر در `http://localhost:8000` پاسخ می‌دهد. بدون SMTP، پیوند ورود در لاگ‌های کانتینر نوشته می‌شود (`docker compose logs core-app`).

راهنماهای کامل (به انگلیسی): **[نصب](docs/INSTALLATION.en.md)** (از ماشین خالی تا دفتر روی https، SMTP، کارخانهٔ نرم‌افزار، پشتیبان‌ها، عیب‌یابی)، **[راهنمای کاربر](docs/MODE-D-EMPLOI.en.md)** (هر صفحه، عامل‌ها، تصمیم‌ها، هزینه). عکس‌های بنیان‌گذار و عامل‌ها در [`portraits/`](portraits/README.md) قرار می‌گیرند (توضیح به فرانسوی).

از ایمیج منتشرشده، بدون ساخت محلی (`CORE_IMAGE_TAG=v…` در `.env` برای ثابت‌کردن نسخه):

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

محلی بدون Docker:

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## امنیت

آنچه هسته تضمین می‌کند و آزمایش می‌شود (`tests/test_securite.py`):

- **ماژول‌ها**: ماژول فقط با امضای ناشر (Ed25519) نصب و اجرا می‌شود و امضا هش SHA-256 هر فایل کد را پوشش می‌دهد: فایلی که پس از امضا تغییر کرده، افزوده یا حذف شده باشد ماژول را از کار می‌اندازد.
- **ورود**: پیوندهای یک‌بارمصرف ۲۰ دقیقه‌ای، به‌صورت هش در پایگاه داده؛ ترمزهایی به‌ازای هر نشانی، هر IP و سراسری روی درخواست‌های پیوند، تا دفتر هرگز رلهٔ ایمیل نشود؛ بدون پیکربندی SMTP در محیط تولید هیچ پیوندی ساخته یا ثبت نمی‌شود.
- **فرم‌ها**: کوکی نشست HMAC با `HttpOnly` و `SameSite=Strict`، بررسی مبدأ و توکن ضد CSRF به‌ازای هر نشست در هر POST.
- **صفحه‌ها**: سیاست امنیت محتوای سخت‌گیرانه (`default-src 'self'`، بدون اسکریپت درون‌خطی، بدون فریم)، `nosniff`، `X-Frame-Options`، `Referrer-Policy`، و HSTS وقتی مبدأ https است.
- **عامل‌ها**: هر آنچه عامل می‌خواند (صفحهٔ وب، فایل مخزن) به‌صورت محتوای بیرونیِ قاب‌شده به او می‌رسد، هرگز به‌عنوان دستور؛ عامل فقط ابزارهای کارت خود را اجرا می‌کند و به‌محض خواندن دادهٔ خصوصی، فقط می‌تواند سایت شرکت را فراخوانی کند؛ فقط نشانی‌های https عمومی را می‌خواند (نشانی‌های خصوصی، loopback، link-local و نام‌های داخلی در هر گام تغییر مسیر رد می‌شوند، پاسخ محدود است)؛ دروازهٔ امنیتی رازها، فایل‌های زیرساخت، اسکریپت‌های شخص ثالث، فریم‌ها و فراخوانی‌های شبکه را مسدود می‌کند.
- **کانتینر**: کاربر بدون امتیاز، سیستم فایل فقط‌خواندنی، بدون capability، بدون ارتقای امتیاز؛ کلید میزبان سرور SSH قابل ثابت‌کردن است (`SSH_CLE_HOTE`).
- **خروجی حسابداری**: سلول‌هایی که شبیه فرمول صفحه‌گسترده هستند خنثی می‌شوند.

گزارش آسیب‌پذیری: `securite@zelij.ai`، بدون انتشار پیش از رفع. پیش از هر نسخه، `pip-audit -r requirements.txt` و `bandit -r core scripts -ll` باید خالی برگردند.

## مشارکت و پیگیری نسخه‌ها

`CONTRIBUTING.md` (به فرانسوی) می‌گوید یک مشارکت چگونه به یک نسخه می‌رسد، از جمله این قاعده: مقصد استقراری که مشارکت داده شود، بستهٔ متناظر را مادام‌العمر رایگان می‌کند. `SECURITY.md` می‌گوید چگونه آسیب‌پذیری را گزارش کنید. `CHANGELOG.md` می‌گوید هر نسخه چه چیزی را تغییر می‌دهد و چه کاری برای بنیان‌گذار باقی می‌ماند.

## آزمون‌ها و کنترل انتشار

```bash
python -m pytest -q
python scripts/controle_publication.py
```

کنترل انتشار کلیدها، نشانی‌های IP، کدهای داخلی، نشانی‌های ایمیل شخصی، گذرواژه‌های متن‌ساده و واژه‌های یک فهرست خصوصی (`ZELIJ_CORE_INTERDITS`) را که هرگز بخشی از مخزن نیست رد می‌کند.
