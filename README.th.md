**สร้างสตาร์ทอัพที่เป็น AI-native 100 % ของคุณ** สำนักงานเดียวที่เอเจนต์สี่ตัวทำงานให้คุณ: พวกเขาเสนอ คุณตัดสินใจ เครื่องของคุณ คีย์ Claude ของคุณ ข้อมูลของคุณ ไม่มีอะไรส่งออกไปหาใครทั้งสิ้น

![อควาเรียมของ Zelij Core: ผู้ก่อตั้งและเอเจนต์สี่ตัวพูดคุย เสนอการตัดสินใจ และลงมือทำสิ่งที่ได้รับอนุมัติ](docs/img/aquarium.gif)

*อควาเรียมในหนึ่งวันจำลอง (ในภาพเป็นภาษาฝรั่งเศส) ในการติดตั้งของคุณ การ์ดแต่ละใบคือการกระทำจริงของเอเจนต์ แสดงสดและเล่นซ้ำได้ย้อนหลังยี่สิบสี่ชั่วโมง สีทองคือคุณ: ไม่มีสิ่งใดที่มีผลผูกพันเกิดขึ้นก่อนการตัดสินใจของคุณ ใบหน้าทั้งหมดเป็นตัวละครสมมติ*

## แกนหลักทำอะไรได้บ้าง

- **สำนักงาน**: หน้าเดียว การตัดสินใจที่รออยู่ คำขอถึงหัวหน้าคณะทำงาน การรันล่าสุดพร้อมต้นทุน บันทึกประจำวัน เอเจนต์ และโมดูลที่ติดตั้ง
- **ชุดการตัดสินใจ**: เป้าหมาย ข้อเสนอ ทำไมต้องตอนนี้ ทางเลือก คำแนะนำ ความเสี่ยง ความสามารถในการย้อนกลับ แผน การถอยกลับ ผลกระทบ ชุดที่ไม่ครบจะเปิดไม่ได้ อนุมัติ ปฏิเสธ หรือขอแก้ไขพร้อมคำสั่งบังคับที่ส่งต่อไปยังเอเจนต์
- **กฎของบ้าน**: ไม่มีสิ่งใดที่มีผลผูกพัน (เงิน การเปิดเผยต่อสาธารณะ การลบ สิ่งที่ย้อนกลับไม่ได้) เกิดขึ้นโดยไม่มีการตัดสินใจ ข้อเท็จจริงต้องมีวันที่และแหล่งอ้างอิง หรือถูกทำเครื่องหมายว่า « ยังไม่ได้ตรวจสอบ » บันทึกประจำวันไม่ถูกลบ
- **เกตเวย์**: คีย์ Claude ของผู้ก่อตั้ง ต้นทุนของการเรียกแต่ละครั้งคำนวณจากการใช้งานและราคาสาธารณะที่ระบุวันที่ เพดานรายเดือนที่จะบล็อกเมื่อถึง
- **ตัวดำเนินการ**: ลูปการเรียกที่มีขอบเขต (งบรอบต่อเอเจนต์) เครื่องมือที่ประหยัด การปฏิเสธของโมเดลถือเป็นผลลัพธ์หนึ่ง
- **โมดูล**: ทางเดียวในการขยายแกนหลัก อินเทอร์เฟซที่เสถียร ไฟล์ `pack.json` ที่ผู้เผยแพร่ลงนามด้วย Ed25519 แฮชของทุกไฟล์อยู่ภายใต้ลายเซ็น ตรวจสอบก่อนติดตั้ง เป้าหมายการติดตั้งใช้งานและเอเจนต์เพิ่มเติมทั้งหมดผ่านทางนี้
- **การเงิน**: ยอดขายที่ยืนยันแล้ว (นำเข้า Stripe แบบอ่านอย่างเดียว หรือป้อนเองพร้อมหลักฐาน) ค่าใช้จ่ายที่แจ้งไว้และเกิดซ้ำทุกเดือน ต้นทุนเอเจนต์ที่วัดได้ สมุดบัญชีรายเดือน ส่งออก CSV ให้นักบัญชี ไม่มีการยื่นภาษีหรือออกใบแจ้งหนี้
- **ผู้ติดต่อ**: หนึ่งการ์ดต่อหนึ่งคน ฐานทางกฎหมายที่บังคับ ระยะเวลาเก็บรักษา การติดต่อ สิทธิที่ใช้ไป ผู้ติดต่อที่คัดค้านจะไม่ได้รับอะไรอีก ผู้ติดต่อที่หมดอายุจะถูกลืมและเหลือเพียงบันทึกเรื่องสิทธิ
- **การเผยแพร่**: หน้าที่เอเจนต์การตลาดเขียนกลายเป็นฉบับร่าง แล้วกลายเป็นการตัดสินใจ เมื่ออนุมัติแล้วจะถูกเสนอให้เว็บไซต์ในรูป pull request ของ GitHub หรือฉบับร่าง WordPress ขั้นตอนสุดท้าย คือการรวมหรือเผยแพร่ เป็นของคุณ
- **อยู่ในกระเป๋า**: ทุกการตัดสินใจมาถึงโทรศัพท์ของคุณ ทางอีเมลพร้อมลิงก์ลงนามใช้ครั้งเดียวสองลิงก์ หรือทาง Telegram พร้อมปุ่มสามปุ่ม คุณอนุมัติระหว่างต่อแถวรถไฟฟ้า อควาเรียมขยับทันทีที่คุณตอบ ประตูเดียวกัน บันทึกเดียวกันกับที่โต๊ะทำงาน
- **อควาเรียม**: ดูเอเจนต์ของคุณทำงาน ฟองแต่ละฟองคือการกระทำจริงใน 24 ชั่วโมงที่ผ่านมา วงแหวนเส้นประคือตำแหน่งที่ว่าง หน้าสาธารณะที่แชร์ได้ พร้อมป้าย « by zelij.ai »
- **แคตตาล็อก**: สิ่งที่รุ่นฟรีไม่มี ระบุชื่ออย่างตรงไปตรงมา โมดูลที่ซื้อจากผู้เผยแพร่ติดตั้งที่นี่ ลงนามและตรวจสอบแล้ว ไม่มีการชำระเงินใดผ่านสำนักงาน
- **โรงงานซอฟต์แวร์**: ผู้สร้างอ่านและเสนอบนที่เก็บโค้ดเพียงแห่งเดียว ผ่าน pull request ที่ผ่านประตูความปลอดภัย (300 บรรทัด ข้อความเท่านั้น ไม่มีความลับ ไม่มีไฟล์โครงสร้างพื้นฐาน ไลบรารีที่ไม่มีช่องโหว่ที่รู้จักตาม OSV) นำขึ้นเซิร์ฟเวอร์ Linux ผ่าน SSH หรือที่ OVH (โดเมนและ DNS ผ่าน API) พร้อมการสลับแบบอะตอมมิก การทดสอบควันและการถอยกลับ ตรวจสอบโดเมน สำรองข้อมูลสำนักงานทุกวัน มันไม่เคยรวมโค้ด ไม่เคยจ่ายเงิน ไม่เคยแตะต้องสำนักงาน
- **เอเจนต์**: หนึ่งโฟลเดอร์ต่อเอเจนต์ ไฟล์ `agent.md` ที่มีส่วนหัวเรียบง่ายและคำสั่งเป็นภาษาฝรั่งเศส เอเจนต์สี่ตัว: Camille Aubert (หัวหน้าคณะทำงาน), Élise Tanguy (การเติบโต การตลาด และผลิตภัณฑ์), Nour Bellamy (การเงินและลูกค้า), Sacha Ferrand (ผู้สร้าง โรงงานซอฟต์แวร์) ผู้ก่อตั้งคุยกับแต่ละคนจากสำนักงาน ชุดที่อนุมัติแล้วซึ่งระบุเอเจนต์และงานจะถูกดำเนินการทันทีภายในขอบเขตของแผน

## ทดลองในหนึ่งนาที ไม่ต้องใช้คีย์

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

เปิด `http://localhost:8000` แล้วเข้าสู่การสาธิต: บริษัทสมมติ เอเจนต์จำลองสี่ตัว การตัดสินใจที่ต้องอนุมัติ อควาเรียมที่เล่นซ้ำวันทำงานของพวกเขา ไม่ต้องใช้คีย์ ไม่ต้องมีบัญชี ไม่มีค่าใช้จ่าย ไม่มีอะไรถูกส่งไปยังโมเดลและทุกอย่างหายไปเมื่อหยุด เมื่อมั่นใจแล้ว ไปต่อที่การติดตั้งจริงด้านล่าง ตัวสำนักงานเองเป็นภาษาฝรั่งเศส

## เริ่มต้น

```bash
cp .env.example .env     # คีย์ Claude เพดาน SECRET_KEY รหัสผ่านฐานข้อมูล
docker compose up -d --build
```

สำนักงานตอบที่ `http://localhost:8000` หากไม่มี SMTP ลิงก์เข้าสู่ระบบจะถูกเขียนลงในล็อกของคอนเทนเนอร์ (`docker compose logs core-app`)

คู่มือฉบับเต็ม (ภาษาอังกฤษ): **[การติดตั้ง](docs/INSTALLATION.en.md)** (จากเครื่องเปล่าถึงสำนักงานบน https, SMTP, โรงงานซอฟต์แวร์, การสำรองข้อมูล, การแก้ปัญหา), **[คู่มือการใช้งาน](docs/MODE-D-EMPLOI.en.md)** (ทุกหน้า เอเจนต์ การตัดสินใจ ต้นทุน) รูปของผู้ก่อตั้งและเอเจนต์วางไว้ใน [`portraits/`](portraits/README.md) (คำอธิบายเป็นภาษาฝรั่งเศส)

จากอิมเมจที่เผยแพร่ โดยไม่ต้องสร้างในเครื่อง (`CORE_IMAGE_TAG=v…` ใน `.env` เพื่อตรึงเวอร์ชัน):

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

รันในเครื่องโดยไม่ใช้ Docker:

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## ความปลอดภัย

สิ่งที่แกนหลักรับประกันและมีการทดสอบ (`tests/test_securite.py`):

- **โมดูล**: โมดูลจะติดตั้งและทำงานได้ก็ต่อเมื่อผู้เผยแพร่ลงนาม (Ed25519) และลายเซ็นครอบคลุมแฮช SHA-256 ของไฟล์โค้ดทุกไฟล์: ไฟล์ที่ถูกแก้ไข เพิ่ม หรือลบหลังการลงนามจะทำให้โมดูลใช้ไม่ได้
- **การเข้าสู่ระบบ**: ลิงก์ใช้ครั้งเดียวอายุ 20 นาที เก็บแบบแฮชในฐานข้อมูล มีเบรกตามที่อยู่ ตาม IP และแบบรวมสำหรับคำขอลิงก์ เพื่อให้สำนักงานไม่กลายเป็นตัวส่งต่ออีเมล หากไม่ได้ตั้งค่า SMTP ในโปรดักชัน จะไม่มีการสร้างหรือบันทึกลิงก์ใด ๆ
- **ฟอร์ม**: คุกกี้เซสชัน HMAC `HttpOnly` `SameSite=Strict` ตรวจสอบต้นทางและโทเค็นป้องกัน CSRF ต่อเซสชันในทุก POST
- **หน้าเว็บ**: นโยบายความปลอดภัยเนื้อหาแบบเข้มงวด (`default-src 'self'` ไม่มีสคริปต์อินไลน์ ไม่มีเฟรม), `nosniff`, `X-Frame-Options`, `Referrer-Policy`, HSTS เมื่อต้นทางเป็น https
- **เอเจนต์**: สิ่งที่เอเจนต์อ่าน (หน้าเว็บ ไฟล์ในที่เก็บโค้ด) มาถึงในกรอบของเนื้อหาภายนอก ไม่ใช่คำสั่ง เอเจนต์รันเฉพาะเครื่องมือในการ์ดของตน และทันทีที่อ่านข้อมูลส่วนตัวแล้ว จะเรียกได้เฉพาะเว็บไซต์ของบริษัทเท่านั้น อ่านเฉพาะที่อยู่ https สาธารณะ (ที่อยู่ส่วนตัว loopback link-local และชื่อภายในถูกปฏิเสธในทุกขั้นของการเปลี่ยนเส้นทาง การตอบกลับมีขนาดจำกัด) ประตูความปลอดภัยบล็อกความลับ ไฟล์โครงสร้างพื้นฐาน สคริปต์ของบุคคลที่สาม เฟรม และการเรียกเครือข่าย
- **คอนเทนเนอร์**: ผู้ใช้ไม่มีสิทธิพิเศษ ระบบไฟล์อ่านอย่างเดียว ไม่มี capability ไม่มีการยกระดับสิทธิ์ กุญแจโฮสต์ของเซิร์ฟเวอร์ SSH ตรึงได้ (`SSH_CLE_HOTE`)
- **การส่งออกบัญชี**: เซลล์ที่ดูเหมือนสูตรสเปรดชีตจะถูกทำให้เป็นกลาง

รายงานช่องโหว่ที่ `securite@zelij.ai` โดยไม่เปิดเผยก่อนแก้ไข ก่อนทุกเวอร์ชัน `pip-audit -r requirements.txt` และ `bandit -r core scripts -ll` ต้องไม่พบอะไรเลย

## การมีส่วนร่วมและเวอร์ชัน

`CONTRIBUTING.md` (ภาษาฝรั่งเศส) อธิบายว่าการมีส่วนร่วมเข้าสู่เวอร์ชันได้อย่างไร รวมถึงกฎที่ว่า เป้าหมายการติดตั้งใช้งานที่คุณมีส่วนร่วมจะได้รับแพ็กที่ตรงกันฟรีตลอดชีพ `SECURITY.md` อธิบายวิธีรายงานช่องโหว่ `CHANGELOG.md` บอกว่าแต่ละเวอร์ชันเปลี่ยนอะไรและผู้ก่อตั้งต้องทำอะไรต่อ
