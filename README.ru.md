**Постройте стартап, на 100 % созданный для ИИ.** Один офис, где четыре агента работают на вас: они предлагают, вы решаете. Ваша машина, ваш ключ Claude, ваши данные; ничто никуда не «звонит».

![Аквариум Zelij Core: основатель и четыре агента общаются, предлагают решения и выполняют одобренное](docs/img/aquarium.gif)

*Аквариум за один смоделированный день (здесь на французском). В вашей установке каждая карточка — реальное действие ваших агентов, в прямом эфире и с повтором за двадцать четыре часа. Золото — это вы: ничто обязывающее не происходит до вашего решения. Лица принадлежат вымышленным персонажам.*

## Что делает ядро

- **Офис**: одна страница. Ожидающие решения, запрос руководителю аппарата, последние запуски с их стоимостью, журнал, агенты, установленные модули.
- **Пакет решения**: цель, предложение, почему сейчас, варианты, рекомендация, риски, обратимость, план, откат, эффект. Неполный пакет не открывается. Одобрить, отклонить или запросить изменения с обязательным указанием, которое передаётся агенту.
- **Правила дома**: ничто обязывающее (деньги, публичность, удаление, необратимое) не делается без решения; факт датирован и снабжён источником либо помечен «не проверено»; журнал не стирается.
- **Шлюз**: ключ Claude основателя, стоимость каждого вызова, рассчитанная по использованию и датированным публичным тарифам, месячный потолок, который блокирует.
- **Исполнитель**: ограниченный цикл вызовов (бюджет ходов на агента), скромные инструменты, отказ модели трактуется как результат.
- **Модули**: единственный способ расширить ядро. Стабильный интерфейс, манифест `pack.json`, подписанный издателем по Ed25519, хеш каждого файла под подписью, проверка перед установкой. Цели развёртывания и дополнительные агенты приходят только этим путём.
- **Финансы**: подтверждённые продажи (импорт Stripe только для чтения или ввод вручную с подтверждением), заявленные расходы, повторяющиеся каждый месяц, измеренная стоимость агентов, журнал месяца, экспорт CSV для бухгалтера. Ничего не декларируется и не выставляется к оплате.
- **Контакты**: одна карточка на человека, обязательное правовое основание, срок хранения, переписка, реализованные права; возразивший контакт больше ничего не получает, истёкший контакт забывается, остаётся только журнал прав.
- **Публикация**: страница, написанная маркетинговым агентом, становится черновиком, затем решением; одобренная, она предлагается сайту как pull request в GitHub или черновик WordPress. Последний шаг, слияние или публикация, за вами.
- **В кармане**: каждое решение приходит на ваш телефон — по электронной почте с двумя подписанными одноразовыми ссылками или в Telegram с тремя кнопками. Вы одобряете в очереди в метро; аквариум оживает, как только вы ответили. Та же дверь, тот же журнал, что и с рабочего стола.
- **Аквариум**: смотрите, как работают ваши агенты; каждый пузырь — реальное действие за последние 24 часа, пунктирные кольца — свободные должности. Публичная страница, которой можно делиться, со значком «by zelij.ai».
- **Каталог**: то, чего нет в свободной редакции, названо честно; модуль, купленный у издателя, устанавливается здесь, подписанный и проверенный. Никакая оплата не проходит через офис.
- **Фабрика ПО**: Строитель читает и предлагает в одном-единственном репозитории через pull request'ы, прошедшие ворота безопасности (300 строк, только текст, без секретов, без инфраструктурных файлов, зависимости без известных уязвимостей по OSV); развёртывание на Linux-сервер по SSH или в OVH (домен и DNS через API) с атомарным переключением, дымовым тестом и откатом; зонд домена; ежедневная резервная копия офиса. Он никогда не сливает, никогда не платит, никогда не трогает офис.
- **Агенты**: одна папка на агента, `agent.md` с простым заголовком и указаниями на французском. Четыре агента: Camille Aubert (руководитель аппарата), Élise Tanguy (рост, маркетинг и продукты), Nour Bellamy (финансы и клиенты), Sacha Ferrand (строитель, фабрика ПО). Основатель обращается к каждому из офиса; одобренный пакет, называющий агента и задачу, выполняется сразу, в пределах плана.

## Попробовать за минуту, без ключа

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

Откройте `http://localhost:8000` и войдите в демонстрацию: вымышленная компания, четыре смоделированных агента, решения на одобрение, аквариум, проигрывающий их день. Ни ключа, ни аккаунта, ни расходов; ничего не отправляется модели, и всё исчезает при остановке. Убедившись, переходите к настоящей установке ниже. Сам офис — на французском.

## Запуск

```bash
cp .env.example .env     # ключ Claude, потолок, SECRET_KEY, пароль базы данных
docker compose up -d --build
```

Офис отвечает на `http://localhost:8000`. Без SMTP ссылка для входа пишется в журналы контейнера (`docker compose logs core-app`).

Полные руководства (на английском): **[Установка](docs/INSTALLATION.en.md)** (от пустой машины до офиса по https, SMTP, фабрика ПО, резервные копии, устранение неполадок), **[Руководство пользователя](docs/MODE-D-EMPLOI.en.md)** (каждая страница, агенты, решения, стоимость). Фотографии основателя и агентов кладутся в [`portraits/`](portraits/README.md) (описание на французском).

Из опубликованного образа, без локальной сборки (`CORE_IMAGE_TAG=v…` в `.env` фиксирует версию):

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

Локально без Docker:

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## Безопасность

Что гарантирует ядро и что проверяется тестами (`tests/test_securite.py`):

- **Модули**: модуль устанавливается и запускается только с подписью издателя (Ed25519), и подпись покрывает хеш SHA-256 каждого файла кода: файл, изменённый, добавленный или удалённый после подписания, выводит модуль из игры.
- **Вход**: одноразовые ссылки на 20 минут, хешированные в базе; тормоза по адресу, по IP и глобальные на запросы ссылок, чтобы офис никогда не стал почтовым ретранслятором; без настроенного SMTP в продакшене ссылка не создаётся и не журналируется.
- **Формы**: HMAC-cookie сессии, `HttpOnly`, `SameSite=Strict`, проверка origin и анти-CSRF-токен на сессию при каждом POST.
- **Страницы**: строгая политика безопасности контента (`default-src 'self'`, без встроенных скриптов, без фреймов), `nosniff`, `X-Frame-Options`, `Referrer-Policy`, HSTS при https-origin.
- **Агенты**: всё, что агент читает (веб-страница, файл репозитория), приходит к нему обрамлённым как внешнее содержимое, никогда как указание; агент выполняет только инструменты из своей карточки и, прочитав приватные данные, может обращаться только к сайту компании; он читает только публичные https-адреса (частные, loopback, link-local адреса и внутренние имена отклоняются на каждом переходе редиректа, ответ ограничен по размеру); ворота безопасности блокируют секреты, инфраструктурные файлы, сторонние скрипты, фреймы и сетевые вызовы.
- **Контейнер**: непривилегированный пользователь, файловая система только для чтения, без capabilities, без повышения привилегий; ключ хоста SSH-сервера можно закрепить (`SSH_CLE_HOTE`).
- **Бухгалтерский экспорт**: ячейки, похожие на формулу электронной таблицы, нейтрализуются.

Сообщайте об уязвимостях на `securite@zelij.ai`, не публикуя их до исправления. Перед каждой версией `pip-audit -r requirements.txt` и `bandit -r core scripts -ll` должны возвращать пустой результат.

## Участие и версии

`CONTRIBUTING.md` (на французском) объясняет, как вклад попадает в версию, включая правило: внесённая цель развёртывания даёт соответствующий пакет бесплатно навсегда. `SECURITY.md` объясняет, как сообщить об уязвимости. `CHANGELOG.md` говорит, что меняет каждая версия и что остаётся сделать основателю.

## Тесты и контроль публикации

```bash
python -m pytest -q
python scripts/controle_publication.py
```

Контроль публикации отклоняет ключи, IP-адреса, внутренние коды, личные адреса электронной почты, пароли открытым текстом и термины из закрытого списка (`ZELIJ_CORE_INTERDITS`), который никогда не входит в репозиторий.
