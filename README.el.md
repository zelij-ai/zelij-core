**Στήστε τη 100 % AI-native startup σας.** Ένα γραφείο όπου τέσσερις πράκτορες δουλεύουν για εσάς: αυτοί προτείνουν, εσείς αποφασίζετε. Το μηχάνημά σας, το κλειδί Claude σας, τα δεδομένα σας· τίποτα δεν «τηλεφωνεί» πουθενά.

![Το ενυδρείο του Zelij Core: ο ιδρυτής και τέσσερις πράκτορες συζητούν, προτείνουν αποφάσεις και εκτελούν ό,τι εγκρίθηκε](docs/img/aquarium.gif)

*Το ενυδρείο σε μια προσομοιωμένη ημέρα (εδώ στα γαλλικά). Στη δική σας εγκατάσταση, κάθε κάρτα είναι μια πραγματική ενέργεια των πρακτόρων σας, ζωντανά και με επανάληψη είκοσι τεσσάρων ωρών. Το χρυσό είστε εσείς: τίποτα δεσμευτικό δεν γίνεται πριν από την απόφασή σας. Τα πρόσωπα ανήκουν σε φανταστικούς χαρακτήρες.*

## Τι κάνει ο πυρήνας

- **Το γραφείο**: μία σελίδα. Οι αποφάσεις που εκκρεμούν, ένα αίτημα προς τον διευθυντή του γραφείου, οι τελευταίες εκτελέσεις με το κόστος τους, το ημερολόγιο, οι πράκτορες, τα εγκατεστημένα modules.
- **Το πακέτο απόφασης**: στόχος, πρόταση, γιατί τώρα, επιλογές, σύσταση, κίνδυνοι, αναστρεψιμότητα, σχέδιο, επιστροφή, αντίκτυπος. Ένα ελλιπές πακέτο δεν ανοίγει. Έγκριση, απόρριψη ή αίτημα αλλαγών με υποχρεωτική οδηγία που διαβιβάζεται στον πράκτορα.
- **Οι κανόνες του σπιτιού**: τίποτα δεσμευτικό (χρήματα, δημόσια έκθεση, διαγραφή, μη αναστρέψιμο) δεν γίνεται χωρίς απόφαση· ένα γεγονός έχει ημερομηνία και πηγή ή σημειώνεται «μη επαληθευμένο»· το ημερολόγιο δεν σβήνεται ποτέ.
- **Η πύλη**: το κλειδί Claude του ιδρυτή, το κόστος κάθε κλήσης υπολογισμένο από τη χρήση και τις χρονολογημένες δημόσιες τιμές, ένα μηνιαίο όριο που μπλοκάρει.
- **Ο εκτελεστής**: ένας περιορισμένος βρόχος κλήσεων (προϋπολογισμός γύρων ανά πράκτορα), λιτά εργαλεία, μια άρνηση του μοντέλου αντιμετωπίζεται ως αποτέλεσμα.
- **Τα modules**: ο μόνος τρόπος επέκτασης του πυρήνα. Σταθερή διεπαφή, μανιφέστο `pack.json` υπογεγραμμένο με Ed25519 από τον εκδότη, το αποτύπωμα κάθε αρχείου καλύπτεται από την υπογραφή, επαλήθευση πριν από την εγκατάσταση. Οι στόχοι ανάπτυξης και οι πρόσθετοι πράκτορες περνούν από εδώ.
- **Οικονομικά**: επιβεβαιωμένες πωλήσεις (εισαγωγή Stripe μόνο για ανάγνωση ή χειροκίνητη καταχώριση με απόδειξη), δηλωμένα έξοδα που επαναλαμβάνονται κάθε μήνα, μετρημένο κόστος πρακτόρων, μηνιαίο ημερολόγιο, εξαγωγή CSV για τον λογιστή. Τίποτα δεν δηλώνεται ούτε τιμολογείται.
- **Επαφές**: μία καρτέλα ανά άτομο, υποχρεωτική νομική βάση, διάρκεια διατήρησης, ανταλλαγές, δικαιώματα που ασκήθηκαν· μια επαφή που εναντιώθηκε δεν λαμβάνει πλέον τίποτα, μια ληγμένη επαφή ξεχνιέται και μένει μόνο το ημερολόγιο δικαιωμάτων.
- **Δημοσίευση**: μια σελίδα γραμμένη από τον πράκτορα μάρκετινγκ γίνεται πρόχειρο, μετά απόφαση· εγκεκριμένη, προτείνεται στον ιστότοπο ως pull request του GitHub ή πρόχειρο WordPress. Η τελευταία κίνηση, συγχώνευση ή δημοσίευση, είναι δική σας.
- **Στην τσέπη**: κάθε απόφαση φτάνει στο τηλέφωνό σας, με e-mail με δύο υπογεγραμμένους συνδέσμους μίας χρήσης ή μέσω Telegram με τρία κουμπιά. Εγκρίνετε από την ουρά του μετρό· το ενυδρείο κινείται μόλις απαντήσετε. Ίδια πόρτα, ίδιο ημερολόγιο όπως από το γραφείο.
- **Ενυδρείο**: δείτε τους πράκτορές σας να δουλεύουν· κάθε φυσαλίδα είναι μια πραγματική ενέργεια των τελευταίων 24 ωρών, οι διακεκομμένοι δακτύλιοι είναι κενές θέσεις. Μια δημόσια σελίδα που μοιράζεται, με το σήμα «by zelij.ai».
- **Κατάλογος**: ό,τι δεν περιέχει η ελεύθερη έκδοση, κατονομασμένο με ειλικρίνεια· ένα module που αγοράστηκε από τον εκδότη εγκαθίσταται εδώ, υπογεγραμμένο και επαληθευμένο. Καμία πληρωμή δεν περνά από το γραφείο.
- **Software factory**: ο Κατασκευαστής διαβάζει και προτείνει σε ένα μόνο αποθετήριο, μέσω pull requests που περνούν την πύλη ασφαλείας (300 γραμμές, μόνο κείμενο, κανένα μυστικό, κανένα αρχείο υποδομής, εξαρτήσεις χωρίς γνωστή ευπάθεια μέσω OSV)· ανάπτυξη σε διακομιστή Linux μέσω SSH ή στην OVH (τομέας και DNS μέσω API) με ατομική εναλλαγή, δοκιμή καπνού και επιστροφή· ανιχνευτής τομέα· καθημερινό αντίγραφο ασφαλείας του γραφείου. Ποτέ δεν συγχωνεύει, ποτέ δεν πληρώνει, ποτέ δεν αγγίζει το γραφείο.
- **Οι πράκτορες**: ένας φάκελος ανά πράκτορα, ένα `agent.md` με απλή κεφαλίδα και οδηγίες στα γαλλικά. Τέσσερις πράκτορες: Camille Aubert (διευθύντρια γραφείου), Élise Tanguy (ανάπτυξη, μάρκετινγκ και προϊόντα), Nour Bellamy (οικονομικά και πελάτες), Sacha Ferrand (κατασκευαστής, software factory). Ο ιδρυτής απευθύνεται στον καθένα από το γραφείο· ένα εγκεκριμένο πακέτο που ορίζει πράκτορα και εργασία εκτελείται αμέσως, εντός των ορίων του σχεδίου.

## Δοκιμάστε σε ένα λεπτό, χωρίς κλειδί

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

Ανοίξτε το `http://localhost:8000` και μπείτε στην επίδειξη: μια φανταστική εταιρεία, τέσσερις προσομοιωμένοι πράκτορες, αποφάσεις προς έγκριση, το ενυδρείο που αναπαράγει την ημέρα τους. Κανένα κλειδί, κανένας λογαριασμός, κανένα κόστος· τίποτα δεν στέλνεται σε μοντέλο και όλα εξαφανίζονται με τη διακοπή. Όταν πειστείτε, περάστε στην πραγματική εγκατάσταση παρακάτω. Το ίδιο το γραφείο είναι στα γαλλικά.

## Εκκίνηση

```bash
cp .env.example .env     # κλειδί Claude, όριο, SECRET_KEY, κωδικός βάσης δεδομένων
docker compose up -d --build
```

Το γραφείο απαντά στο `http://localhost:8000`. Χωρίς SMTP, ο σύνδεσμος σύνδεσης γράφεται στα αρχεία καταγραφής του container (`docker compose logs core-app`).

Πλήρεις οδηγοί (στα αγγλικά): **[Εγκατάσταση](docs/INSTALLATION.en.md)** (κενό μηχάνημα → γραφείο σε https, SMTP, software factory, αντίγραφα ασφαλείας, αντιμετώπιση προβλημάτων), **[Οδηγός χρήσης](docs/MODE-D-EMPLOI.en.md)** (κάθε σελίδα, οι πράκτορες, οι αποφάσεις, το κόστος). Οι φωτογραφίες ιδρυτή και πρακτόρων μπαίνουν στο [`portraits/`](portraits/README.md) (περιγραφή στα γαλλικά).

Από τη δημοσιευμένη εικόνα, χωρίς τοπικό build (`CORE_IMAGE_TAG=v…` στο `.env` για κλείδωμα έκδοσης):

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

Τοπικά χωρίς Docker:

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## Ασφάλεια

Τι εγγυάται ο πυρήνας, και τι ελέγχεται (`tests/test_securite.py`):

- **Modules**: ένα module εγκαθίσταται και εκτελείται μόνο υπογεγραμμένο από τον εκδότη (Ed25519), και η υπογραφή καλύπτει το αποτύπωμα SHA-256 κάθε αρχείου κώδικα: ένα αρχείο που τροποποιήθηκε, προστέθηκε ή αφαιρέθηκε μετά την υπογραφή θέτει το module εκτός.
- **Σύνδεση**: σύνδεσμοι μίας χρήσης 20 λεπτών, κατακερματισμένοι στη βάση· φρένα ανά διεύθυνση, ανά IP και καθολικά στα αιτήματα συνδέσμων, ώστε το γραφείο να μην γίνει ποτέ αναμεταδότης e-mail· χωρίς ρυθμισμένο SMTP στην παραγωγή, κανένας σύνδεσμος δεν δημιουργείται ούτε καταγράφεται.
- **Φόρμες**: cookie συνεδρίας HMAC `HttpOnly` `SameSite=Strict`, έλεγχος προέλευσης και διακριτικό anti-CSRF ανά συνεδρία σε κάθε POST.
- **Σελίδες**: αυστηρή πολιτική ασφάλειας περιεχομένου (`default-src 'self'`, κανένα inline script, κανένα frame), `nosniff`, `X-Frame-Options`, `Referrer-Policy`, HSTS όταν η προέλευση είναι https.
- **Πράκτορες**: ό,τι διαβάζει ένας πράκτορας (ιστοσελίδα, αρχείο αποθετηρίου) του φτάνει πλαισιωμένο ως εξωτερικό περιεχόμενο, ποτέ ως οδηγία· ένας πράκτορας εκτελεί μόνο τα εργαλεία της καρτέλας του και, μόλις διαβάσει ιδιωτικό δεδομένο, μπορεί να καλέσει μόνο τον ιστότοπο της εταιρείας· διαβάζει μόνο δημόσιες διευθύνσεις https (ιδιωτικές, loopback, link-local διευθύνσεις και εσωτερικά ονόματα απορρίπτονται σε κάθε άλμα ανακατεύθυνσης, απόκριση με όριο)· η πύλη ασφαλείας μπλοκάρει μυστικά, αρχεία υποδομής, scripts τρίτων, frames και κλήσεις δικτύου.
- **Container**: χρήστης χωρίς προνόμια, σύστημα αρχείων μόνο για ανάγνωση, καμία capability, καμία ανύψωση· το κλειδί κεντρικού υπολογιστή του διακομιστή SSH μπορεί να καρφιτσωθεί (`SSH_CLE_HOTE`).
- **Λογιστική εξαγωγή**: τα κελιά που μοιάζουν με τύπο υπολογιστικού φύλλου εξουδετερώνονται.

Αναφορά ευπάθειας: `securite@zelij.ai`, χωρίς δημοσίευση πριν από τη διόρθωση. Πριν από κάθε έκδοση, τα `pip-audit -r requirements.txt` και `bandit -r core scripts -ll` πρέπει να επιστρέφουν κενά.

## Συνεισφορά και παρακολούθηση εκδόσεων

Το `CONTRIBUTING.md` (στα γαλλικά) εξηγεί πώς μια συνεισφορά φτάνει σε μια έκδοση, συμπεριλαμβανομένου του κανόνα: ένας στόχος ανάπτυξης που συνεισφέρθηκε αξίζει το αντίστοιχο πακέτο δωρεάν για πάντα. Το `SECURITY.md` εξηγεί πώς αναφέρεται μια ευπάθεια. Το `CHANGELOG.md` λέει τι αλλάζει κάθε έκδοση και τι μένει να κάνει ο ιδρυτής.

## Δοκιμές και έλεγχος δημοσίευσης

```bash
python -m pytest -q
python scripts/controle_publication.py
```

Ο έλεγχος δημοσίευσης απορρίπτει κλειδιά, διευθύνσεις IP, εσωτερικούς κωδικούς, προσωπικές διευθύνσεις e-mail, κωδικούς σε καθαρό κείμενο και τους όρους μιας ιδιωτικής λίστας (`ZELIJ_CORE_INTERDITS`) που δεν αποτελεί ποτέ μέρος του αποθετηρίου.
