**100% AI ネイティブなスタートアップを立ち上げる。** 4 人のエージェントがあなたのために働くひとつのオフィス。彼らが提案し、あなたが決める。あなたのマシン、あなたの Claude キー、あなたのデータ。外部に何も送信しません。

![Zelij Core のアクアリウム：創業者と 4 人のエージェントが対話し、決定を提案し、承認されたことを実行する](docs/img/aquarium.gif)

*シミュレートされた一日のアクアリウム（ここではフランス語表示）。あなたのインストールでは、各カードはエージェントの実際の行動で、リアルタイムに表示され、24 時間分を再生できます。金色はあなたです。拘束力のあることは、あなたの決定の前には何も起こりません。顔はすべて架空の人物です。*

## コアができること

- **オフィス**：1 ページ。保留中の決定、首席補佐官への依頼、直近の実行とそのコスト、ジャーナル、エージェント、インストール済みモジュール。
- **決定パケット**：目的、提案、なぜ今か、選択肢、推奨、リスク、可逆性、計画、ロールバック、影響。不完全なパケットは開きません。承認、却下、またはエージェントに渡される必須の指示付きで変更を要求。
- **ハウスルール**：拘束力のあること（お金、公開、削除、不可逆な操作）は決定なしには何も行われない。事実には日付と出典が付くか「未検証」と記される。ジャーナルは消去されない。
- **ゲートウェイ**：創業者の Claude キー。各呼び出しのコストは使用量と日付付きの公開価格から算出され、月間上限に達すると遮断される。
- **実行器**：上限付きの呼び出しループ（エージェントごとのターン予算）、控えめなツール、モデルの拒否はひとつの結果として扱われる。
- **モジュール**：コアを拡張する唯一の方法。安定したインターフェース、発行者が Ed25519 で署名した `pack.json` マニフェスト、各ファイルのハッシュが署名の対象、インストール前の検証。デプロイ先や追加エージェントはすべてここを通ります。
- **財務**：確認済みの売上（Stripe の読み取り専用インポート、または証憑付きの手入力）、毎月繰り返す申告済み経費、計測されたエージェントコスト、月次台帳、会計士向け CSV エクスポート。申告も請求もしません。
- **連絡先**：1 人 1 カード、必須の法的根拠、保存期間、やり取り、行使された権利。異議を申し立てた連絡先には何も送られず、期限切れの連絡先は忘れられ、権利のジャーナルだけが残る。
- **公開**：マーケティングエージェントが書いたページは下書きになり、次に決定になる。承認されると GitHub のプルリクエストまたは WordPress の下書きとしてサイトに提案される。マージまたは公開という最後の一手はあなたのもの。
- **ポケットの中に**：すべての決定があなたの電話に届く。署名付き使い捨てリンク 2 本のメール、または 3 つのボタン付きの Telegram で。地下鉄の列で承認すれば、アクアリウムはすぐ動き出す。デスクからと同じ門、同じジャーナル。
- **アクアリウム**：エージェントが働く様子を眺める。各バブルは直近 24 時間の実際の行動で、点線のリングは空席のポスト。「by zelij.ai」バッジ付きの共有可能な公開ページ。
- **カタログ**：無料版に含まれないものを正直に名指し。発行者から購入したモジュールはここで署名・検証のうえインストールされる。支払いはオフィスを経由しない。
- **ソフトウェアファクトリー**：ビルダーは単一のリポジトリで読み取りと提案を行い、セキュリティゲートを通るプルリクエスト（300 行、テキストのみ、シークレットなし、インフラファイルなし、OSV による既知の脆弱性のない依存関係）で提出する。SSH 経由の Linux サーバーまたは OVH（API によるドメインと DNS）へのデプロイは、アトミックな切り替え、スモークテスト、ロールバック付き。ドメインの監視、オフィスの日次バックアップ。マージも支払いもせず、オフィスに触れることもない。
- **エージェント**：エージェントごとに 1 フォルダ、簡単なヘッダーとフランス語の指示を持つ `agent.md`。4 人のエージェント：Camille Aubert（首席補佐官）、Élise Tanguy（成長、マーケティング、プロダクト）、Nour Bellamy（財務と顧客）、Sacha Ferrand（ビルダー、ソフトウェアファクトリー）。創業者はオフィスから各エージェントに直接話しかけ、エージェントとタスクを指定した承認済みパケットは計画の範囲内でただちに実行される。

## キーなしで 1 分で試す

```bash
git clone https://github.com/zelij-ai/zelij-core.git && cd zelij-core
docker compose -f docker-compose.demo.yml up --build
```

`http://localhost:8000` を開いてデモに入ります。架空の会社、4 人のシミュレートされたエージェント、承認すべき決定、彼らの一日を再生するアクアリウム。キーもアカウントもコストも不要。モデルには何も送られず、停止するとすべて消えます。納得したら、下の本番インストールに進んでください。オフィス自体はフランス語です。

## 起動

```bash
cp .env.example .env     # Claude キー、上限、SECRET_KEY、データベースのパスワード
docker compose up -d --build
```

オフィスは `http://localhost:8000` で応答します。SMTP がない場合、ログインリンクはコンテナのログに書き出されます（`docker compose logs core-app`）。

完全なガイド（英語）：**[インストール](docs/INSTALLATION.en.md)**（何もないマシンから https のオフィスまで、SMTP、ソフトウェアファクトリー、バックアップ、トラブルシューティング）、**[ユーザーガイド](docs/MODE-D-EMPLOI.en.md)**（各ページ、エージェント、決定、コスト）。創業者とエージェントの写真は [`portraits/`](portraits/README.md) に置きます（説明はフランス語）。

公開イメージからローカルビルドなしで（`.env` の `CORE_IMAGE_TAG=v…` でバージョンを固定）：

```bash
docker compose -f docker-compose.yml -f docker-compose.image.yml up -d
```

Docker なしでローカル実行：

```bash
pip install -r requirements-dev.txt
uvicorn core.bureau.app:app --reload
```

## セキュリティ

コアが保証し、テストされていること（`tests/test_securite.py`）：

- **モジュール**：モジュールは発行者の署名（Ed25519）がある場合にのみインストール・実行され、署名は各コードファイルの SHA-256 ハッシュを対象とする。署名後に変更、追加、削除されたファイルがあればモジュールは無効になる。
- **ログイン**：20 分間有効な使い捨てリンク、データベースにはハッシュで保存。リンク要求にはアドレス別、IP 別、全体のブレーキがあり、オフィスがメール中継になることはない。本番で SMTP が未設定なら、リンクは作成も記録もされない。
- **フォーム**：HMAC セッションクッキー、`HttpOnly`、`SameSite=Strict`、すべての POST でオリジン検査とセッションごとの CSRF 対策トークン。
- **ページ**：厳格なコンテンツセキュリティポリシー（`default-src 'self'`、インラインスクリプトなし、フレームなし）、`nosniff`、`X-Frame-Options`、`Referrer-Policy`、オリジンが https なら HSTS。
- **エージェント**：エージェントが読むもの（ウェブページ、リポジトリのファイル）は外部コンテンツとして枠付きで届き、決して指示にはならない。エージェントは自分のカードにあるツールしか実行せず、私的データを読んだ後は会社自身のサイトしか呼び出せない。公開の https アドレスしか読まない（プライベート、ループバック、リンクローカルのアドレスと内部名はリダイレクトのたびに拒否され、応答には上限がある）。セキュリティゲートはシークレット、インフラファイル、サードパーティのスクリプト、フレーム、ネットワーク呼び出しを遮断する。
- **コンテナ**：非特権ユーザー、読み取り専用ファイルシステム、ケーパビリティなし、権限昇格なし。SSH サーバーのホスト鍵を固定できる（`SSH_CLE_HOTE`）。
- **会計エクスポート**：表計算の数式に見えるセルは無害化される。

脆弱性の報告は `securite@zelij.ai` へ、修正前に公開しないでください。各リリースの前に `pip-audit -r requirements.txt` と `bandit -r core scripts -ll` が何も返さないことが条件です。

## 貢献とバージョン

`CONTRIBUTING.md`（フランス語）は、貢献がどのようにリリースに入るかを説明しています。デプロイ先を貢献した人は対応するパックを生涯無料で得られる、というルールも含みます。`SECURITY.md` は脆弱性の報告方法を、`CHANGELOG.md` は各バージョンの変更点と創業者に残る作業を説明します。
